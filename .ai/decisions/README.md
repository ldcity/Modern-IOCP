# Design Decisions

**형식은 로드맵 §10.1 Design Question 을 그대로 쓴다** — 별도 ADR 템플릿을 만들지 않는다
(`../../seamless-world/ROADMAP.md`).

```markdown
# <결정할 질문 한 문장>

## 문제
## 후보
1.
2.
## 선택
## 이유
## 단점
## 재검토 조건
```

🔴 핵심은 채택안이 아니라 **버린 안과 그 이유**다 (로드맵 §9).
AI 산출물에는 "고려했지만 안 한 것" 이 없다 — 그게 본인 설계임을 보이는 가장 강한 신호다.

파일명: `YYYYMMDD-short-question.md`
