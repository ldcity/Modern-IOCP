# Engineering Constitution — Portfolio

두 프로젝트(`modern-iocp/`, `seamless-world/`) 공통 엔지니어링 원칙.

> **적용 순위**: `seamless-world/` 에서는 로드맵 §4(개발 원칙 여섯)가 이 문서보다 우선한다.
> 충돌하면 로드맵을 따르고, 왜 그랬는지 task 문서에 남긴다.
> `modern-iocp/` 는 이 문서가 정본이다.

## 우선순위

- 현재 사용자의 명시적 요청과 승인 범위를 보존한다.
- 정확성·복구 가능성·관측 가능성을 **검증되지 않은 성능 최적화보다** 우선한다.
- AI 가 생성했다는 사실은 품질의 근거가 아니다. 코드·테스트·측정·독립 리뷰를 근거로 삼는다.

## 설계 원칙

- **YAGNI / KISS** — 현재 완료 조건에 필요하지 않은 범용화를 넣지 않는다.
- **Rule of Three / AHA** — 같은 변경 이유가 실제로 세 번 반복되기 전에는 추상화하지 않는다.
- **SRP · 정보 은닉** — 함께 변경되는 것만 묶고, 상태 불변식은 소유 타입 안에 감춘다.
- **계층과 DIP** — 의존 방향은 항상 단방향. 추상 타입은 구현체가 2개 이상이거나 테스트가
  대역을 실제로 요구할 때만 만든다.
- **의도를 드러내는 이름** — 단위·좌표계·소유권을 이름에 넣는다. 주석으로 불명확한 구조를 변명하지 않는다.

원칙끼리 충돌하면 작업 문서에 선택과 근거를 남긴다. 기계적으로 동시 적용하지 않는다.

## C++ 게임 서버 불변식

- 소켓·핸들·버퍼·세션·작업 객체의 **소유자와 해제 시점**을 명확히 한다.
- 공유 상태를 변경할 수 있는 **스레드와 동기화 방식**을 명시한다.
- 종료 가능한 스레드는 stop 신호 → 대기 해제 → join → 자원 해제 순서를 갖는다.
- IO 워커 스레드에서 DB·Redis 같은 **블로킹 I/O 를 실행하지 않는다.**
- 네트워크 길이·ID·enum·배열 인덱스는 **사용 전에 검증한다.**
- 인증 전후 상태를 구분하고 실패·중복·재시도 경로를 **멱등하게** 설계한다.
- 큐와 풀은 **용량·과부하 정책·backpressure** 를 정의한다.
- Lock-free 는 **측정된 병목과 수명 안전성 검증이 있을 때만** 선택한다.
- 성능 주장은 **하드웨어·빌드 설정·부하 모델·p50/p95/p99** 로 재현 가능하게 만든다.

## 측정 규율

이 저장소의 존재 이유 중 하나가 "측정 증거가 있는 포트폴리오" 다. 그래서 아래를 강제한다.

- **측정 없는 최적화 금지.** 최적화 전후 수치를 남긴다. 틱 예산으로 환산한다.
- **벤치 결과에는 commit hash 와 실행 환경을 함께 적는다** (로드맵 §8).
- **판정 앞에 유효성 게이트를 둔다.** 부하가 실제로 걸렸는지 먼저 확인하고,
  안 걸렸으면 PASS/FAIL 이 아니라 **INVALID** 다.
- **"통과했다" 를 의심한다.** 아래는 실제로 겪은 가짜 PASS 유형이다:
  결측값이 0 으로 읽혀 완벽으로 보인 것 · 폴백 응답으로 테스트가 통과한 것 ·
  러너가 대상 코드를 한 줄도 안 밟고 race 0 이 나온 것 · 판정 조건이 정의상 항상 참이던 것.
- 새 검사를 채택하기 전에 **결함을 임시로 되돌려 FAIL 하는 것을 눈으로 확인**한다.

## 저장소 위생과 보안

- 비밀값을 커밋하지 않는다. 예제 설정과 런타임 주입을 분리한다.
- 빌드 산출물·로그·사용자별 IDE 설정·**절대 경로**를 추적하지 않는다.
- 🔴 **업무에서 얻은 자산을 이 저장소에 넣지 않는다.** 회사 코드나 동료 코드에서 얻은 것은
  **코드가 아니라 기법만** 가져오고, 새로 작성한다. 출처를 적을 때도 내부 식별자
  (CL 번호·내부 서버명·이슈 키·사람 이름)를 쓰지 않는다.
- 새 의존성은 목적·대안·라이선스·운영 비용을 설명할 수 있어야 한다.

## 완료의 증거

- 동작 변경에는 **실패 경로를 포함한** 검증이 필요하다.
- 동시성 변경에는 **종료·경쟁·수명 시나리오**가 필요하다.
- 성능 변경에는 **동일 조건의 전후 측정**이 필요하다.
- 실행하지 못한 검사는 숨기지 않고 **이유와 잔여 위험을 기록한다.**
- 빌드를 안 돌렸으면 "빌드 미검증" 이라고 쓴다. 절반 된 것을 완료라고 쓰지 않는다.
